## Local development

### Backend (port 8080)

```bash
cd backend
mvn spring-boot:run
```

Health check: `curl http://localhost:8080/actuator/health`
Sample endpoint: `curl http://localhost:8080/api/books`

### Frontend (port 3000)

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000.

### Both together (with Docker)

```bash
docker compose up --build
```

## CI/CD

Every push to `main` triggers `.github/workflows/ci.yml`:
- Backend: `mvn package`
- Frontend: `npm run typecheck && npm run build`

Deployment is wired in `.github/workflows/deploy.yml` (added by Forge during scaffolding).
